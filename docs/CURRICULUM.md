## 초안 대비 바꾼 것

받은 4일 초안에서 **순서 세 곳을 고치고, 빠진 것을 채우고, 역전파를 줄였다.**

### 순서

| 초안 | 바꾼 것 | 이유 |
|---|---|---|
| 자료형 → 곧바로 OOP | 자료형 → **조건·반복·함수** → (Day 4) OOP | `def`를 모르는 상태에서 `class`·`__init__`·`self`는 안 붙는다. OOP는 `nn.Module`이 눈앞에 있는 Day 4로 옮겼다 |
| List Comprehension을 `for` 전에 | `for` → `range` → `while` → **컴프리헨션** | 접기 전에 펴진 형태를 먼저 본다 |
| 미분(Day 2) ↔ 경사 하강법(Day 4) | 둘을 **Day 3 오전에 붙였다** | 이틀 간격이면 잊는다. 기울기를 배운 직후 바로 굴려 본다 |

### 채운 것

| 추가 | 어디 | 없으면 |
|---|---|---|
| 조건문 · 반복문 · 함수 | Day 1 CH4·CH5 | 초안에 통째로 없었다. 나머지가 전부 공중에 뜬다 |
| **Pandas** | Day 2 CH0 (15장) | 초안에 없는데 Day 4 과제가 "Tabular 전처리"였다. CSV를 NumPy로 전처리할 수는 없다 |
| **전처리** — 결측·인코딩·스케일링 | Day 2 CH1 (8장) | 스케일링을 빼면 Day 4에서 **손실이 안 떨어진다**. 실습 실패의 직접 원인 |
| **시각화** | Day 2 CH2 (6장) | 손실 곡선을 못 그리면 학습 성공 여부를 확인할 수단이 없다 |
| **과적합 · 교차 검증** | Day 3 CH3 | 초안은 train/test split만 있었다. 훈련 정확도만 보고 보고하게 된다 |
| **평가 지표 확장** | Day 3 CH3 | 초안은 "Accuracy, MSE 등". 불균형 데이터에서 정확도가 무의미하다는 것을 스팸 예제(97%)로 보인다 |
| **에러 읽는 법** | Day 4 CH3 (2장) | shape 에러는 PyTorch 실습에서 100% 만난다 |
| **로컬 환경 세팅** | Day 1 CH0 (4장) | Anaconda 설치 · 가상 환경 · Jupyter Lab. 사내 데이터는 밖으로 못 내보내므로 로컬 경로가 필요하다 |
| **불변과 가변** | Day 1 #21~23, #51 | 요청 반영. 아래 별도 항목 |
| 하루 끝 워크타임 | 전 일 | 참고 교안에는 있었는데 초안에서 빠졌다. 완주율을 가른다 (슬라이드에는 표기하지 않는다) |

### 줄인 것

| 초안 | 바꾼 것 | 근거 |
|---|---|---|
| 역전파 이론 3h + Autograd 2h | **1.5h** — 연쇄 법칙 그림 1장 + `backward()` 3줄 | 이 청중은 역전파를 직접 구현하지 않는다. SGD/Adam 비교도 한 장으로 줄였다 |

| 입과식 1.5h | **1h** | |

### 뺀 것 — 커리큘럼 안내

과정 구조를 설명하는 슬라이드를 전부 없앴다. 무엇을 배울지, 지난 회차에 무엇을 했는지는
**강사가 말로 한다.** 슬라이드에 넣으면 아직 안 배운 개념이 앞으로 끌려 나온다.

| 없앤 것 | 이유 |
|---|---|
| Day 1 CH0 챕터 5장 (전체 흐름 · 나흘 동안 하는 일 · 1주차와 2주차의 경계 · AI가 하는 일 · 에러 없이 돌아가는 오답) | 첫 시간에 `groupby`·회귀·LLM이 이름부터 나온다. 배울 준비가 안 된 청중에게 소음이다 |
| Day 4 나흘 정리 · 2주차 로드맵 2장 | 전체 회고와 다음 주 예고. Day 4 내용만 남긴 정리 한 장으로 대체했다 |
| 각 덱의 `다음` keymsg 4곳 | `Day 2는 …를 다룬다` 같은 예고 |
| 회차 상호 참조 60곳 | `Day 2의 get_dummies` → `get_dummies`. 회차 번호 대신 개념 이름으로 부른다 |
| 시각 표기 전부 | `17:00–18:00 워크타임`, `09:00 · CH0`, `15:00 – 17:30` |
| 표지의 `.lead` · `.meta`, 간지의 설명문 `<p>` | 기준 덱은 표지가 `kick + h1`뿐이고 간지에 설명문이 없다 |

lint가 이 여섯 가지를 전부 막는다 — `회차 언급`, `시간 표기`, `제목 서술문` 규칙.

## 불변과 가변

요청하신 항목이라 세 장으로 나눠 넣었다. 원시 타입 / 참조 타입이라는 다른 언어의 용어는
쓰지 않는다. 파이썬은 전부 객체이므로 **가변성**만으로 설명이 끝난다.

| # | 제목 | 내용 |
|---|---|---|
| 21 | 값이 바뀌는 자료형과 바뀌지 않는 자료형 | `int/float/str/tuple` vs `list/dict/set`. `b = a` 후 결과가 갈리는 코드 두 개 |
| 22 | 대입과 복사의 차이 | `.slots` 메모리 도해 + `id()`로 확인. `b = a`는 복사가 아니라 이름을 더 붙이는 것 |
| 23 | 얕은 복사와 깊은 복사 | 중첩 구조에서 `.copy()`가 안 통하는 코드 + `copy.deepcopy()`. 3행 비교표 |
| 51 | 함수가 고칠 수 있는 인자와 못 하는 인자 | `add_one(x)`는 밖이 안 바뀌고 `append_one(lst)`는 바뀐다 |

## 데이터셋

**타이타닉** 891행 12열. 나흘 내내 같은 데이터를 쓴다.

- 결측이 있다 — `Age` 177개, `Cabin` 687개, `Embarked` 2개
- 범주형이 있다 — `Sex`, `Embarked`, `Pclass`
- 이상치가 있다 — `Fare` 최대 512 대 중앙값 14
- 답과 관계가 뚜렷하다 — 여성 74% 대 남성 19% 생존

전처리 네 단계, groupby, 상관 히트맵, 모델 비교, MLP 학습이 전부 이 한 표에서 나온다.
새 데이터를 이해하는 데 드는 시간이 사라지고, 인지 부하가 준다.

회귀 설명은 **주택 가격**을 쓰되, 예제 일부는 **소재 공정**으로 잡았다 —
소성 온도 → 방전 용량(회귀), 입도·이물 수 → 양품/불량(분류).

Day 3 의 평가 지표 전체(혼동 행렬 · 정확도의 함정 · 정밀도/재현율 · 지표 선택)를
**불량 검출**로 다시 썼다. 놓친 불량은 고객 클레임, 헛경보는 라인 정지 — 비용이
비대칭이라 지표 선택을 설명하기에 맞다.

Day 2 에는 `손대기 전의 표` 한 장을 넣어 현장 CSV 가 어떻게 오는지 보인다
(쉼표·단위 혼입, 결측 표기 불일치, 대소문자·공백 흔들림).

**회사명은 넣지 않는다.** 공개 저장소이므로 업종 일반 용어만 쓴다.
