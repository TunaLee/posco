# 이차전지 양극재 소성 공정 데이터

**실제 데이터가 아니다.** 강의용으로 난수에서 만든 가상의 **양극재 소성 공정** 기록이다.
전구체를 리튬과 섞어 소성한 배치마다 조건과 결과를 적어 둔 표라고 보면 된다.
회사·설비·제품을 특정하지 않는다. 생성기는 [`data/make_dataset.py`](../../data/make_dataset.py)에 있고
시드가 고정돼 있어 언제 돌려도 같은 파일이 나온다.

## 심어 둔 것

읽자마자 손봐야 할 것들이 일부러 들어 있다.

| 문제 | 어디에 | 배우는 것 |
|---|---|---|
| 결측 표기가 `N/A` `-` `''`로 제각각 | `입도` `수분율` | `na_values` · `isnull` · `fillna` |
| 천 단위 쉼표 탓에 `object` 타입 | `불순물` | `dtype` 확인 · `to_numeric` · `thousands=','` |
| 대소문자·공백 흔들림 | `설비호기` | `str.strip().str.upper()` |
| 센서 오류값 | `성형압력` | 이상치 탐지 · 박스플롯 |
| 같은 배치가 두 번 | 12행 | `duplicated` · `drop_duplicates` |
| 정답 불균형 18.8% | `양품여부` | 정확도의 함정 · 정밀도/재현율 |
| 답과 무관한 열 | `성형압력` (상관 −0.04) | 상관 히트맵 읽기 |

## 방전용량 과의 상관

```
소성온도   +0.76      ← 가장 강하다
소성시간   +0.17
불순물    −0.25
입도     −0.16
수분율    −0.14
성형압력   −0.04      ← 사실상 무관
```

온도는 **890 °C 부근이 최적**이고 대부분의 배치가 그 아래에 있다.
그래서 상관은 뚜렷한 양수로 나오지만 관계 자체는 곡선이다 —
선형 회귀도 어느 정도 맞히고, 트리 계열이 더 잘 맞힌다.
