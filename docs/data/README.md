# 이차전지 양극재 소성 공정 데이터

**실제 데이터가 아니다.** 강의용으로 난수에서 만든 가상의 **양극재 소성 공정** 기록이다.
전구체를 리튬과 섞어 소성한 배치마다 조건과 결과를 적어 둔 표라고 보면 된다.
회사·설비·제품을 특정하지 않는다. 생성기는 [`data/make_dataset.py`](../../data/make_dataset.py)에 있고
시드가 고정돼 있어 언제 돌려도 같은 파일이 나온다.

## 불러오기

```python
import pandas as pd

url = 'https://tunalee.github.io/posco/data/batch_quality.csv'
df = pd.read_csv(url)

# 열 이름이 한글이다 — df['소성온도'] 처럼 쓴다
```

## 심어 둔 것

읽자마자 손봐야 할 것들이 일부러 들어 있다.

| 문제 | 어디에 | 배우는 것 |
|---|---|---|
| 결측 표기가 `N/A` `-` `''`로 제각각 | `입도` `수분율` | `na_values` · `isnull` · `fillna` |
| 천 단위 쉼표 탓에 `object` 타입 | `불순물` | `dtype` 확인 · `to_numeric` · `thousands=','` |
| 대소문자·공백 흔들림 | `설비호기` | `str.strip().str.upper()` |
| 센서 오류값 | `성형압력` | 이상치 탐지 · 박스플롯 |
| 같은 배치가 두 번 | 12행 | `duplicated` · `drop_duplicates` |
| 정답 불균형 18.8% | `양품여부` | 정확도의 함정 · 정밀도/재현율 |
| 답과 무관한 열 | `성형압력` (상관 −0.04) | 상관 히트맵 읽기 |

## 방전용량 과의 상관

```
소성온도   +0.76      ← 가장 강하다
소성시간   +0.17
불순물    −0.25
입도     −0.16
수분율    −0.14
성형압력   −0.04      ← 사실상 무관
```

온도는 **890 °C 부근이 최적**이고 대부분의 배치가 그 아래에 있다.
그래서 상관은 뚜렷한 양수로 나오지만 관계 자체는 곡선이다 —
선형 회귀도 어느 정도 맞히고, 트리 계열이 더 잘 맞힌다.

# 셀 공정 시계열 — cell_process.csv

**실제 데이터가 아니다.** 난수로 만든 가상의 **이차전지 셀 제조 라인** 기록이다.
회사·설비·제품을 특정하지 않고, 값은 문헌에 흔히 보이는 범위 안에서 임의로 잡았다.
생성기는 [`data/make_cell_process.py`](../../data/make_cell_process.py)에 있고 시드가 고정돼 있다.

「그대로 내보내면 안 되는 표」의 본보기로 쓴다. 반출본 만들기 실습(day9 11절)이 이 파일을 읽는다.

```python
url = 'https://tunalee.github.io/posco/data/cell_process.csv'
df = pd.read_csv(url, parse_dates=['시각'])
```

|---|---|

# RAG 실습용 문서 — docs/data/docs/*.txt

**실제 법령 조문**이다. 지어낸 글이 아니라서 검색 결과를 원문과 대조할 수 있다.
법령은 저작권법 제7조에 따라 보호 대상이 아니라 그대로 쓸 수 있다.
수집기는 [`data/fetch_docs.py`](../../data/fetch_docs.py), 출처는 위키문헌이다.

| 파일 | 문서 | 크기 | 왜 이걸 쓰나 |
|---|---|---|---|
| `labor_standards.txt` | 근로기준법 | 27,417자 | 연차 · 근로시간 — 누구나 물어보는 것 |
| `occupational_safety.txt` | 산업안전보건법 | 56,954자 | 안전보건교육 · 작업중지 — 현장 질문 |
| `industrial_tech.txt` | 산업기술의 유출방지 및 보호에 관한 법률 | 16,794자 | 국가핵심기술 — 반출 통제와 이어진다 |
| `privacy.txt` | 개인정보 보호법 | 39,615자 | 수집 · 이용 · 파기 |

조문 단위로 자르면 **354조각**, 평균 391자가 된다.

```python
url = 'https://tunalee.github.io/posco/data/docs/labor_standards.txt'
```
