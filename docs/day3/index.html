CH1모델

점들 사이를 지나는 하나의 직선

→

MSE = (1/n) Σ (y − ŷ)²

CH1수학

한 점에서의 기울어진 정도

→
기울기는 "x를 아주 조금 늘리면 y가 얼마나 변하는가"다. 미분이 이것을 구하는 도구다.
→
기울기가 양수면 오른쪽으로 갈수록 값이 커진다. 음수면 작아진다.
★
기울기가 0인 지점이 바닥이다. 손실이 가장 작은 곳이다.
공식을 몰라도 코드로 잰다
def f(x):
    return x ** 2          # 손실 곡선이라 치자

def slope(x, h=1e-5):
    return (f(x + h) - f(x)) / h

print(slope(3))    # 오른쪽 비탈
print(slope(-3))   # 왼쪽 비탈
print(slope(0))    # 바닥
6.00001 -5.99999 1e-05
정리
미분 공식을 외울 필요는 없다. 기울기가 알려 주는 것은 "어느 쪽이 내리막인가" 하나다.
/
CH1학습

기울기 반대 방향의 한 걸음

1

기울기를 잰다

지금의 w에서 손실이 어느 쪽으로 기울어 있는지 계산한다.

2

반대로 움직인다

w = w − 학습률 × 기울기. 손실이 줄어드는 쪽이다.

3

반복한다

손실이 더 줄지 않을 때까지 되풀이한다.

직접 굴려 보면
w, lr = 4.0, 0.3
for step in range(4):
    grad = 2 * w          # f(w)=w² 의 기울기
    w = w - lr * grad
    print(round(w, 3))
1.6 0.64 0.256 0.102
울퉁불퉁하면 진짜 바닥이 아닌 웅덩이에 갇힌다
정리
학습은 손실 곡면을 내려가는 일이다. 손실이 줄지 않으면 내려갈 방향을 못 찾고 있다는 뜻이다.
/
CH1학습

한 걸음의 크기

너무 작으면

느리다

바닥까지 수천 번 걸린다. 시간 안에 끝나지 않는다.

적정

수렴한다

몇 번 만에 바닥 근처에 안착한다.

너무 크면

발산한다

바닥을 건너뛰며 튄다. 손실이 NaN이 된다.

★
손실이 줄다가 갑자기 치솟거나 NaN이 되면 학습률부터 줄인다.
→
흔한 시작값은 0.01 또는 0.001이다. 10배씩 바꿔 가며 확인한다.
→
Adam은 걸음 크기를 스스로 조절해 주는 최적화 알고리즘이다.
기준
학습률은 학습이 되느냐 마느냐를 정하는 값이다. 다른 설정을 만지기 전에 이것부터 맞춘다.

CH3함정

훈련 데이터만 잘 맞히는 모델

과소적합

Underfitting

너무 단순해 훈련도 못 맞힌다. 특성이 부족하거나 모델이 약하다.

적정

Good fit

큰 흐름을 잡고 잡음은 흘려보낸다. 새 데이터에도 통한다.

과대적합

Overfitting

점 하나하나를 외운다. 훈련 성적은 최고, 실전은 최악이다.

깊이를 안 막은 트리 — 훈련 100%
tree = DecisionTreeClassifier().fit(X_train, y_train)
print(tree.score(X_train, y_train), tree.score(X_test, y_test))
0.9831 0.7486 ← 24%p 차이
함정
훈련 정확도 98%는 좋은 신호가 아니다. 훈련과 테스트의 차이가 과적합의 크기다.
/
CH3대응

외우지 못하게 만드는 방법들

1

데이터를 늘린다

가장 확실하다. 외울 양이 많아지면 규칙을 찾는 편이 쉬워진다.

2

모델을 단순하게

트리 깊이를 제한하고, 특성 수를 줄인다. max_depth=6.

3

규제 regularization

가중치가 커지면 벌점을 준다. 특정 특성에 쏠리는 것을 막는다.

4

조기 종료 early stopping

검증 오차가 다시 올라가기 시작하면 학습을 멈춘다. 신경망 학습에서 쓴다.

기준
훈련 오차가 계속 내려가는데 검증 오차가 올라가기 시작하는 지점이 과적합의 시작이다. 거기서 멈춘다.

    s = cross_val_score(m, X, y, cv=5)

기준선(최빈값) 0.616 ± 0.001 로지스틱 회귀 0.799 ± 0.019 결정 트리 0.816 ± 0.024 랜덤 포레스트 0.821 ± 0.017

기준
점수 하나가 아니라 평균 ± 편차로 본다. 편차 안에 들어오는 차이는 차이가 아니다.

CH3평가

잡은 것의 정확함과 놓친 것의 양

정밀도 Precision

TP / (TP + FP) 불량이라고 판정한 것 중 진짜 불량의 비율

낮으면 헛경보가 많다. 멀쩡한 로트가 재검사로 돌아간다.

재현율 Recall

TP / (TP + FN) 진짜 불량 중 걸러낸 것의 비율

낮으면 놓친다. 불량이 그대로 출하된다.

앞 장의 혼동 행렬로 계산하면
# TP=18  FP=40  FN=12
precision = 18 / (18 + 40)
recall    = 18 / (18 + 12)

더 비싼 쪽의 실수

상황더 아픈 실수우선 지표
출하 전 불량 검사놓침 (FN) — 고객 클레임재현율
재검사 비용이 큰 공정헛경보 (FP) — 라인이 멈춘다정밀도
설비 이상 예지놓침 (FN) — 설비 손상재현율
둘 다 비슷할 때—F1
F1 = 2 · (P · R) / (P + R)
→
F1은 정밀도와 재현율의 조화평균이다. 한쪽이 낮으면 F1도 같이 낮아진다.
→
산술평균이 아닌 이유가 그것이다. P=1.0, R=0.1이면 산술평균은 0.55지만 F1은 0.18이다.
★

손에 남는 것

1

학습은 오차를 줄이는 반복이다

손실 함수를 정하고, 기울기 반대로 조금씩 움직인다. 학습률이 그 걸음 크기다.

2

scikit-learn은 네 줄로 돈다

만들고 · fit · predict · score. 모델을 바꿔도 나머지가 그대로라 비교가 쉽다.

3

훈련 성적은 성적이 아니다

훈련과 테스트의 차이가 과적합의 크기다. 데이터가 적으면 교차 검증으로 본다.

4

기준선을 먼저 만든다

최빈값으로 찍어 61.6%. 이걸 못 이기는 모델은 쓸 이유가 없다.

5

지표는 비용에서 나온다

불균형 데이터에서 정확도는 무의미하다. 놓침이 비싸면 재현율, 헛경보가 비싸면 정밀도.

기준
점수 하나로 모델을 판정하지 않는다. 기준선 · 검증 방식 · 지표가 같이 적혀야 성적표다.
