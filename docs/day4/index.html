설계도와 그것으로 찍은 것

class · __init__ · self
class Counter:
    def __init__(self, start=0):
        self.count = start        # 속성

    def tick(self, n=1):        # 메서드
        self.count = self.count + n
        return self.count

a = Counter()          # 인스턴스 1
b = Counter(start=100) # 인스턴스 2

a.tick(); a.tick()
print(a.count, b.count)

CH0상속

남이 만든 설계도의 재사용

상속 — 괄호 안에 부모를 적는다
class StepCounter(Counter):      # Counter 를 물려받는다
    def __init__(self, step=10):
        super().__init__(start=0)  # 부모 초기화 먼저
        self.step = step

    def tick(self, n=None):        # 재정의 overriding
        return super().tick(self.step)

c = StepCounter(step=5)
c.tick(); c.tick()
print(c.count)
10
→
부모의 속성과 메서드를 그대로 물려받는다. 필요한 것만 새로 쓴다.
→
같은 이름으로 다시 정의하면 재정의(overriding)다. 부모 것 대신 이게 불린다.
★
super().__init__()을 빠뜨리면 부모가 준비하던 것이 없어 나중에 에러가 난다.

PyTorch 모델이 이 모양이다

class MLP(nn.Module)로 상속받고, super().__init__()을 부르고, forward()를 재정의한다. 지금 배운 세 가지가 전부다.

기준

CH1구조

층 사이에 끼우는 굽힘

ReLU

은닉층의 기본

max(0, x). 음수는 0으로, 양수는 그대로. 계산이 가장 싸다.

Sigmoid

이진 분류 출력

0~1로 눌러 담아 확률로 읽는다. 로지스틱 회귀와 같다.

Softmax

다중 분류 출력

여러 칸의 합이 1이 되도록 만든다. 클래스별 확률.

없으면 층을 쌓는 뜻이 없다

직선을 직선에 통과시키면 여전히 직선이다. 중간에 굽혀야 곡선 경계가 나온다.

★
은닉층은 ReLU, 출력층은 과제에 맞춰 고른다. 이 조합이 사실상 표준이다.
기준
고민할 자리는 은닉층이 아니라 출력층이다. 회귀는 그대로, 이진 분류는 sigmoid, 다중 분류는 softmax.

순전파의 식

import numpy as np

x  = np.random.randn(4, 8)    # 승객 4명, 특성 8개
W1 = np.random.randn(8, 16)   # 8 → 16

CH2모델

nn.Module로 만드는 모델

앞 장에서 배운 상속 그대로
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, n_in, n_hidden=16):
        super().__init__()              # 부모 초기화
        self.fc1 = nn.Linear(n_in, n_hidden)
        self.fc2 = nn.Linear(n_hidden, 1)
        self.act = nn.ReLU()

    def forward(self, x):            # 재정의
        h = self.act(self.fc1(x))
        return self.fc2(h)

model = MLP(n_in=8)
print(model)
MLP( (fc1): Linear(in_features=8, out_features=16) (fc2): Linear(in_features=16, out_features=1) (act): ReLU() )
→
nn.Linear(8, 16)이 Wx + b를 담당한다. 가중치는 알아서 초기화된다.
→
forward()에 데이터가 흐르는 순서를 적는다. 앞 장의 식 그대로다.
★
호출은 model(x)로 한다. model.forward(x)를 직접 부르지 않는다.
✕
super().__init__()을 빠뜨리면 파라미터가 등록되지 않아 학습이 안 된다.
shape 를 먼저 확인한다
out = model(torch.randn(4, 8))
print(out.shape)
torch.Size([4, 1])
기준
모델을 만들면 학습 전에 랜덤 입력을 한 번 통과시켜 본다. shape 에러를 여기서 다 잡는다.

예측

오차

CH2원리

loss.backward()가 하는 일

→
경사 하강법에는 기울기가 필요했다. 층이 여러 개면 각 가중치의 기울기를 따로 구해야 한다.
→
출력 쪽 오차를 입력 쪽으로 거슬러 나눠 보내며 계산한다. 이것이 역전파다.
→
수학적으로는 연쇄 법칙(Chain Rule)이다. 곱해 가며 뒤로 전달한다.
★
PyTorch가 전부 자동으로 한다. 순전파를 적으면 역전파는 따라온다.
직접 확인해 보면

정리
역전파를 손으로 계산할 일은 없다. 알아야 할 것은 backward()가 기울기를 채우고 step()이 가중치를 옮긴다는 것뿐이다.

CH3정리

손에 남는 것

1

클래스는 상태를 지닌 것에 쓴다

가중치를 계속 들고 있어야 하므로 모델은 클래스다. 상속 · super() · 메서드 재정의 셋이면 된다.

2

층 하나는 f(Wx + b)

행렬 곱 한 번, 덧셈 한 번, 활성화 한 번. 활성화가 없으면 아무리 쌓아도 직선이다.

3

학습 루프는 다섯 줄이다

예측 · 오차 · zero_grad · backward · step. 역전파는 프레임워크가 한다.

4

shape 를 먼저 확인한다

학습 전에 랜덤 입력을 한 번 통과시킨다. 에러 메시지의 괄호 두 개만 보면 풀린다.

5

안 되면 입력과 학습률부터

구조를 바꾸기 전에 스케일링·dtype·lr을 본다. 20행으로 일부러 외우게 해 보는 것이 가장 빠른 진단이다.

기준
신경망이라고 원리가 달라지지 않는다. 손실을 정하고 기울기 반대로 내려가는 것은 그대로다.
