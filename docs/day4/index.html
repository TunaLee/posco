CH1모델

nn.Sequential 로 안 되는 것

순서대로만 흐를 때

입력 → Linear → ReLU → Linear → 예측

nn.Sequential 로 충분하다. 층을 적어 놓으면 끝이다.

중간에 손을 대야 할 때

입력 → Linear → ReLU → 중간값을 따로 꺼내 본다 → 조건에 따라 다른 층으로

순서만 적어서는 표현할 수 없다. 흐름을 직접 쓰는 자리가 필요하다.

기준
클래스는 문법 숙제가 아니다. 흐름을 내가 쓰고 싶어질 때 꺼내는 도구다.

CH1모델

nn.Module 의 두 칸

앞 장의 Sequential 과 같은 모델
class Net(nn.Module):
    def __init__(self):     # 1. 쓸 층을 만들어 둔다
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)

    def forward(self, x):   # 2. 흐르는 순서를 쓴다
        x = x.flatten(1)
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        return self.fc3(x)

net = Net()
→
__init__ 은 재료를 꺼내 놓는 칸이다. 층을 만들어 self. 에 붙여 둔다.
★
forward 는 흐름을 쓰는 칸이다. 여기 적은 대로 값이 지나간다.
→
super().__init__() 은 PyTorch 가 층을 찾을 수 있게 등록하는 한 줄이다. 빠지면 학습이 안 된다.
→
net(xb) 라고 쓰면 forward 가 불린다. 직접 부르지 않는다.
기준
외울 것은 두 칸뿐이다 — 재료를 놓는 칸과 흐름을 쓰는 칸.

CH4학습

6만 장을 나눠 넣는 이유

DataLoader 가 잘라서 내준다
from torch.utils.data import DataLoader
torch.manual_seed(42)          # 섞는 순서까지 고정한다

loader = DataLoader(train, batch_size=128, shuffle=True)
loss_fn = nn.CrossEntropyLoss()          # 열 갈래용
opt = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(5):
    for xb, yb in loader:      # 128장씩 469번
        opt.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward(); opt.step()
✕

→
루프가 두 겹이 된다. 바깥이 에폭, 안이 배치다.

CH3학습

틀린 정도를 숫자 하나로 만드는 계산

열 갈래에 고르게 퍼져 있다 — 아무거나 찍는 것과 같다
2 한 자리에 몰렸다
손실 = −ln(정답 자리의 확률)
학습 전 −ln(0.089) = 2.422  →  5 에폭 뒤 −ln(0.998) = 0.002
기준
정답 자리의 확률이 1 에 가까울수록 손실이 0 에 가깝다. 학습이란 이 숫자를 낮추는 일이다.

loss_fn = nn.CrossEntropyLoss()
opt = torch.optim.Adam(model.parameters(), lr=0.001)

for xb, yb in loader:            # 128장씩
    opt.zero_grad()            # 1. 지난 기울기를 비운다
    pred = model(xb)           # 2. 예측한다
    loss = loss_fn(pred, yb)   # 3. 얼마나 틀렸나
    loss.backward()            # 4. 기울기를 구한다
    opt.step()                 # 5. 한 걸음 옮긴다
★
4번이 역전파, 5번이 경사 하강법이다. 앞에서 본 걸음이 이 두 줄이다.
→
달라진 것은 하나다 — 기울기를 손으로 구하지 않는다.
→
모델을 바꿔도 이 다섯 줄은 그대로다. 외워 두면 끝까지 쓴다.
기준
순서가 정해져 있다. 비우고 · 예측하고 · 재고 · 기울기 구하고 · 옮긴다.
/
CH2학습

기울기를 비우는 한 줄

opt.zero_grad() 를 넣으면

1회차 기울기 0.42 2회차 기울기 0.31 3회차 기울기 0.25

매번 이번 회차의 기울기만 남는다. 손실이 고르게 줄어든다.

빼먹으면

1회차 기울기 0.42 2회차 기울기 0.73 ← 0.42 + 0.31 3회차 기울기 0.98 ← 계속 쌓인다

기울기가 더해져 걸음이 점점 커진다. 손실이 튀거나 발산한다.

함정
PyTorch 는 기울기를 지우지 않고 더한다. 그것이 기본 동작이라 매 회차 직접 비워야 한다.
