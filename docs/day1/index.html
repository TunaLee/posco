CH1연산

나눗셈이 세 종류인 이유

연산자뜻예
+ - *더하기 빼기 곱하기7 * 2 → 14
/나누기 — 결과는 항상 float6 / 2 → 3.0
//몫만 (버림)7 // 2 → 3
%나머지7 % 2 → 1
**거듭제곱2 ** 10 → 1024
/ 와 // 의 차이
print(6 / 2)     # 나누어 떨어져도
print(7 // 2)
print(7 % 2)

# 짝수 판별에 % 를 쓴다
print(10 % 2 == 0)
3.0 3 1 True
✕
/는 나누어 떨어져도 float를 준다. 인덱스 계산에 쓰면 에러가 난다.
기준
개수나 인덱스처럼 정수가 필요할 때는 //를 쓴다. %는 짝수 판별과 주기 처리의 기본 도구다.

문자열에서 자주 쓰는 메서드

메서드하는 일예
.strip()양끝 공백 제거" a " → "a"
.lower()  ·  .upper()대소문자 통일"Ab" → "ab"
.replace(a, b)바꾸기"1,0" → "10"

sep.join(lst)리스트를 이어 붙임['a','b'] → "a,b"

CH1변수

값이 바뀌는 자료형과 바뀌지 않는 자료형

불변 immutable

int · float · str · tuple

한 번 만들어진 값은 고칠 수 없다. "바꾼다"는 것은 새 값을 만들어 이름을 옮겨 붙이는 일이다.

가변 mutable

list · dict · set

값 자체를 제자리에서 고친다. 그 값을 가리키던 모든 이름이 같이 바뀐다.
불변 — 안전하다
a = 10
b = a
b = b + 5      # 새 정수 15를 만든다
print(a, b)
10 15
가변 — 같이 바뀐다
a = [1, 2]
b = a
b.append(3)    # 그 리스트를 직접 고친다
print(a, b)
[1, 2, 3] [1, 2, 3]
함정
b = a는 복사가 아니다. 이름 하나를 더 붙였을 뿐이다.
