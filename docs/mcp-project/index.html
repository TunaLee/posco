CH1실행

mcp.run 이 하는 일

→
기다린다 — 붙으러 오는 클라이언트를 받으려고 그 자리에 머문다.

★

threading.Thread(
    target=lambda: srv.run(transport='http', port=8931),
    daemon=True).start()
전송 방식은 인자로
transport 를 안 주면 stdio, 주면 HTTP 다. 몸통은 안 바뀐다.

CH2전달

모델에게 넘어가는 것 셋

서버가 내보내는 글 전부
이름    defect_rate
설명    설비호기의 불량률을 돌려준다. 교대조를 주면 그 안에서만 센다.
        machine: 설비호기. 1호기 ~ 4호기
        shift: 교대조. 주간 또는 야간. 비우면 전체
스키마  {
          "machine": {"type": "string"},
          "shift":   {"type": "string", "default": ""}
        }
여기 없는 것은 모른다
함수 몸통은 안 넘어간다. 코드가 아무리 정확해도 이름과 설명이 흐리면 못 고른다.

CH2설명

설명은 모델이 읽는 글

사람에게 쓰는 글

"데이터를 본다"

"불량률 계산 로직 v2"

무엇을 하는지는 알겠는데 언제 쓰는지가 없다

모델에게 쓰는 글

"설비호기의 불량률을 돌려준다.

 품질·불량·양품을 물으면 이것을 쓴다."

「언제 쓰는지」가 판단의 근거가 된다
★
인자 설명도 같이 적는다 — machine: 설비호기. 1호기 ~ 4호기. 모델이 넣을 값을 안다.
한 줄로
설명은 문서가 아니라 지시문이다.

CH2실측

같은 질문 세 번의 결과

Q 3호기 불량률 알려줘 1회 → ['check_quality'] 2회 → ['check_quality'] 3회 → ['check_quality'] Q 3호기 상태 좀 봐줘 1회 → ['check_runtime'] 2회 → ['check_quality', 'check_runtime'] 3회 → ['check_quality', 'check_runtime']
→
뜻이 분명한 질문은 세 번 다 같다.
→
모호한 질문은 매번 다르다. 온도를 0 으로 놓아도 그렇다.
그래서
도구를 좁게 만들고 이름을 분명하게 짓는다. 한 도구가 여러 일을 하면 판단할 근거가 없다.

CH2실측

없는 설비에 돌아온 두 가지 글

같은 질문에 도구 둘이 돌려준 글

터졌다 → Error calling tool 'defect_rate': float division by zero

# 길을 알려 주는 도구
「7호기」 는 없는 설비다. 쓸 수 있는 이름: 1호기, 2호기, 3호기, 4호기
★
이 두 줄이 모델에게 넘어가는 글이다. 앞엣것으로는 무엇이 잘못됐는지 모른다.
에러 문구도
사람만 읽는 것이 아니다. 쓸 수 있는 값을 같이 준다.

CH2위험

빈 값을 채우려는 버릇

검증 없는 도구 7호기 불량률을 조회하려고 했으나 오류가 발생했습니다. 이 오류는 일반적으로 데이터가 존재하지 않거나…   ← 짐작으로 메운다 길을 알려 준 도구 제공된 정보에 따르면 1호기, 2호기, 3호기, 4호기 만 존재합니다. ### 현재 가능한 기기별 불량률 (최신 데이터, 가상 데이터로 대체…   ← 이어 붙이려 든다
★
둘 다 지어내려 든다. 도구가 값을 안 주면 모델은 빈자리를 메우려 한다.

CH3설계

지우는 도구를 만든다면

지운 것을 버리지 않는다
@mcp.tool()
def remove_note(number: int) -> str:
    "점검 메모를 지운다. 지운 것은 되살릴 수 있게 따로 둔다."
    if not 1 <= number <= len(NOTES):
        return '1 부터 %d 사이 번호를 준다' % len(NOTES)
    TRASH.append(NOTES.pop(number - 1))   # ← 버리지 않는다
    return '지웠다. 되살리려면 되살리기 도구를 쓴다'
★
지우는 도구와 되살리는 도구를 짝으로 만든다. 되살리기가 없으면 실수 한 번이 그대로 남는다.
범위도 좁힌다
「번호 하나」만 받는다. 「조건에 맞는 것 전부」를 받으면 한 번에 다 날아간다.

CH3표시

readOnlyHint 가 하는 일

붙는 앱에게 주는 표시
@mcp.tool(annotations={'readOnlyHint': True})

@mcp.tool(annotations={'readOnlyHint': False,
                      'destructiveHint': True})

→
앱은 이걸 보고 「그냥 실행」과 「사람에게 물어보고」를 가른다.
★

표시는 표시일 뿐
자물쇠가 아니라 라벨이다.

CH5작성

Dockerfile 여섯 줄

Dockerfile
FROM python:3.12-slim          # 바탕. 파이썬이 깔린 최소 리눅스

WORKDIR /app                     # 상자 안에서 일할 자리
COPY requirements.txt .         # 꾸러미 목록을 넣고
RUN pip install --no-cache-dir -r requirements.txt

COPY server.py .                # 서버 파일을 넣는다
EXPOSE 8000
CMD ["fastmcp", "run", "server.py",
     "--transport", "http", "--host", "0.0.0.0", "--port", "8000"]
전송 방식은 여기서
server.py 는 mcp.run() 한 줄로 끝난다. 어떻게 띄울지는 상자가 정한다.

CH6문제

손으로 띄울 때 드는 일

CH6작성

compose.yml 한 장

compose.yml
services:
  team1:
    build: ./teams/team1
    expose: ["8000"]        # team2 도 같은 모양

  host:
    build: ./host
    ports: ["8080:8080"]
    environment:
      TEAM_URLS: "http://team1:8000/mcp,http://team2:8000/mcp"
    depends_on: [team1, team2]
한 파일이 전부다
서비스 셋을 적었다. docker compose up 한 줄이면 셋 다 뜬다.

CH6연결

서비스 이름이 곧 주소

TEAM_URLS: "http://team1:8000/mcp,http://team2:8000/mcp" ↑ 기계 이름이 아니라 서비스 이름이다
→
compose 가 서비스마다 이름을 붙여 서로 찾게 이어 준다.
→
IP 를 적을 일이 없다. 컨테이너가 다시 떠서 IP 가 바뀌어도 이름은 그대로다.
★
조가 늘면 서비스 한 칸과 주소 하나만 더 적는다.
한 줄로
team1 이라고 쓰면 그 상자로 간다.

CH6경계

안쪽만 열기와 바깥까지 열기

expose

expose: ["8000"]

같은 compose 안의 다른 서비스만 붙는다.
바깥 브라우저로는 못 연다.

조별 서버 — 호스트만 쓰면 된다

ports

ports: ["8080:8080"]

바깥까지 연다. 브라우저로 열린다.
같은 망의 다른 PC 도 붙는다.

호스트 하나만 이렇게 연다
밖으로 낸 것은 하나
조별 서버를 ports 로 열면 아무나 직접 부른다. 열 까닭이 없다.

CH9정리

오늘 손에 남는 것

1
mcp.run() 한 줄이 서버를 띄운다. 그 순간 주소가 생긴다.
2
Client() 괄호 안만 바뀐다. 서버가 어디에 있든 붙는 쪽은 같다.
3
모델이 받는 것은 이름 · 설명 · 스키마 셋뿐이다. 몸통은 안 간다.
4
권한은 프롬프트가 아니라 만들 도구를 고르는 것으로 정한다.
5
도구 이름은 전역이다. 서버를 여럿 붙일 때는 접두어로 가른다.
한 가지 더
컨테이너는 한 덩이로 싸고, compose 는 그 덩이 여럿을 이름으로 잇는다.

CH9오개념

자주 어긋나는 것 넷

흔한 생각실제
서버를 띄우면 아무나 못 붙는다0.0.0.0 으로 열면 같은 망의 누구나 붙는다
프롬프트로 「지우지 마라」 하면 안 지운다지우는 도구가 있으면 언젠가 불린다
readOnlyHint 가 쓰기를 막는다표시일 뿐이다. 막는 것은 도구 안에서 한다
서버 이름이 다르면 도구 이름은 겹쳐도 된다앱 안에서 전역이라 말없이 덮인다
